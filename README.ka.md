# Docs2Chat: AI ჩატი თქვენი საიტისთვის

**ღია კოდის AI ჩატ-ვიჯეტი. მომხმარებელს პასუხობს თქვენი FAQ-ის, საიტის გვერდებისა და PDF-ების მიხედვით
ქართულად, ინგლისურად და რუსულად. რთულ საუბარს Telegram-ში გადასცემს ადამიანს.**

🇬🇧 English: [README.md](README.md) · 💰 **როგორ ვიშოვო ფული და როგორ მივიღო თანხა:** [docs/MONETIZATION.ka.md](docs/MONETIZATION.ka.md)

## რას აკეთებს

- 📚 **ცოდნის ბაზა**: კითხვა-პასუხი (FAQ), PDF, საიტის გვერდები (ერთი გვერდი ან მთელი საიტი), ჩვეულებრივი ტექსტი.
- 🤖 **AI პასუხები მხოლოდ თქვენი ინფორმაციიდან**: Claude, OpenAI ან უფასო ლოკალური Ollama. თუ პასუხი არ იცის, პირდაპირ ამბობს და ოპერატორთან დაკავშირებას სთავაზობს. **API გასაღების გარეშეც მუშაობს**: ამ შემთხვევაში ყველაზე შესაბამის FAQ-ს ან ტექსტის ნაწყვეტს აჩვენებს.
- 🇬🇪 **3 ენა**: ვიჯეტი ქართულად, ინგლისურად და რუსულად. ვიზიტორის ენას თავად ცნობს.
- ✈️ **Telegram ოპერატორი**: ღილაკი „ოპერატორთან დაკავშირება“ ჩატს თქვენს Telegram-ში აგზავნის. შეტყობინებას **Reply**-ით პასუხობთ და ვიზიტორი პასუხს საიტზევე ხედავს. `/done` ჩატს ისევ AI-ს უბრუნებს.
- 📇 **კონტაქტები (lead-ები)**: სახელი, ტელეფონი, ელ-ფოსტა, სტატუსი, შეკვეთის თანხა, CSV ექსპორტი.
- 📊 **ანალიტიკა**: ყველაზე ხშირი და **უპასუხო კითხვები**. უპასუხო კითხვას პასუხს ერთი დაწკაპუნებით უმატებთ.
- 🏢 **მზადაა ფასიანი SaaS-ისთვის**: პაკეტები, თვიური ლიმიტები, Paddle გამოწერები, ბანკით გადახდის ხელით დადასტურება, ყველა კლიენტის სია და თვიური შემოსავალი (MRR).

## გაშვება ერთი ბრძანებით

```bash
git clone https://github.com/tengotengo23/AI-Support-Chatbot-Knowledge-Base-Widget.git docs2chat
cd docs2chat
cp .env.example .env
docker compose up -d
```

გახსენით <http://localhost:8000/admin>, შექმენით ანგარიში, დაამატეთ რამდენიმე კითხვა-პასუხი და დააჭირეთ
**საიტზე დაყენება → გადახედვა**.

### AI-ს ჩართვა

`.env` ფაილში:

```env
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...
```

### Telegram

1. [@BotFather](https://t.me/BotFather)-ში შექმენით ბოტი და ტოკენი ჩაწერეთ `TELEGRAM_BOT_TOKEN`-ში.
2. გადატვირთეთ (`docker compose restart`). **პარამეტრები → Telegram-ის დაკავშირება**, შემდეგ ბოტში დააჭირეთ *Start*-ს.
3. ოპერატორის მოთხოვნისას ჩატი Telegram-ში მოვა. პასუხისთვის შეტყობინებას **Reply** გაუკეთეთ.

### საიტზე ჩასმა

ადმინ-პანელში **საიტზე დაყენება** გვერდიდან დააკოპირეთ ერთი ხაზი და ჩასვით საიტზე `</body>`-მდე:

```html
<script src="https://your-server/widget.js" data-key="pk_..." async></script>
```

მუშაობს WordPress-ზე, Shopify-ზე, Wix-ზე, Tilda-ზე და ნებისმიერ HTML საიტზე.

## ფასიანი (hosted) ვერსია

`.env`-ში `BILLING_ENABLED=true` რთავს SaaS რეჟიმს: `/` მისამართზე ჩნდება landing გვერდი ფასებით,
ახალი მომხმარებლები უფასო პაკეტს იღებენ და ლიმიტები მოქმედებს. ყველაფერი დეტალურად, მათ შორის
როგორ მიიღოთ თანხა ბანკში, აღწერილია აქ: [docs/MONETIZATION.ka.md](docs/MONETIZATION.ka.md).
