მოგვიანებით, როცა ბევრი კლიენტი გეყოლება, შეგიძლია ქართული ბანკის ონლაინ ბარათით გადახდაც დაამატო
(TBC / საქართველოს ბანკის e-commerce API). ეს roadmap-შია.

#### 🌍 საერთაშორისო კლიენტები: Paddle (ბარათით, ავტომატურად)

**რატომ Paddle და არა Stripe:** Stripe საქართველოში რეგისტრირებულ გამყიდველებს (ჯერჯერობით) არ ემსახურება.
Paddle კი არის *merchant of record*: ის თავად ყიდის შენს პროდუქტს, იხდის VAT-ს და sales tax-ს მთელ მსოფლიოში,
აწერს ინვოისებს და შენ **ყოველთვიურად გირიცხავს** ბანკში (SWIFT) ან Payoneer-ზე.
საკომისიო დაახლოებით 5% + $0.50 თითო გადახდაზე (მიმდინარე ტარიფი paddle.com-ზე ნახე).

კოდი უკვე მზადაა, მხოლოდ გამართვა გჭირდება:

1. დარეგისტრირდი [paddle.com](https://www.paddle.com)-ზე და გაიარე ვერიფიკაცია. საიტზე მოგთხოვენ
   **Terms of Service**, **Privacy Policy** და **Refund Policy** გვერდებს.
2. ჯერ სცადე **Sandbox** გარემოში (`PADDLE_ENV=sandbox`).
3. **Catalog → Products**: შექმენი პროდუქტი და 3 ყოველთვიური ფასი ($19 / $49 / $99).
   მიღებული `pri_...` ID-ები ჩაწერე `.env`-ში:
   ```env
   PADDLE_PRICE_STARTER=pri_...
   PADDLE_PRICE_PRO=pri_...
   PADDLE_PRICE_BUSINESS=pri_...
   ```
4. **Developer tools → Authentication**: შექმენი *client-side token* და ჩაწერე `PADDLE_CLIENT_TOKEN`-ში.
5. **Developer tools → Notifications**: დაამატე destination
   `https://შენი-დომენი/api/billing/paddle/webhook`, მონიშნე `subscription.*` მოვლენები
   და secret ჩაწერე `PADDLE_WEBHOOK_SECRET`-ში.
6. გადატვირთე სერვერი, კლიენტის ანგარიშიდან დააჭირე **„არჩევა“** და გადაიხადე სატესტო ბარათით.
   პაკეტი რამდენიმე წამში ავტომატურად უნდა შეიცვალოს.
7. როცა ყველაფერი მუშაობს: `PADDLE_ENV=production`, production-ის ტოკენები და ფასების ID-ები.
8. Paddle-ის პანელში **Payouts** განყოფილებაში მიუთითე შენი USD ანგარიში (IBAN/SWIFT) ან Payoneer.

#### ☕ შემოწირულობები (არასავალდებულო)

GitHub Sponsors-ზე გადახდა Stripe-ის გავლით ხდება და საქართველო შეიძლება მხარდაჭერილ ქვეყნებში არ იყოს.
